## 🚀 Features

Current modules include:

- 🌐 Website Pinger
- 🆔 UUID Generator
- 👤 Fake Identity Generator (Name / Email / Address combos)
- 🔐 Base64 Encoder / Decoder
- 📺 YouTube Downloader (yt-dlp)
- 🎵 Spotify Downloader (spotdl)

More tools may be added over time.

---

## 📦 Requirements

- Python 3.10+
- pip
- ffmpeg (must be installed and added to your system PATH)

Install dependencies:

```bash
pip install yt-dlp spotdl
```

---

## ▶️ Running the Tool

Run the main file:

```bash
python main.py
```

Or double‑click `main.py` if Python is associated with `.py` files on your system.

---

## 📂 Output

- YouTube downloads are saved inside the `downloads/` folder.
- Spotify downloads may save inside the script directory depending on configuration.
